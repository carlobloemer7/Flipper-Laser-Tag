# Flipper-Laser-Tag
This is a app for the Flipper Zero, that lets you use your Flipper zero as a Laser Tag Weapon for the "Sharper image" Laser Tag gun. It were coded by claude.
The Firmware, i compiled it is the RougeMaster Firmware Version RM0722-1811-ff9f4feb.
You can compile it yourselve.

To use the app, please follow these steps:

1. Drag the lasertek.ir file in the infrared folder of your Flipper Zero ( /ext/infrared )
2. Drag the .fap file wherever you want on your Flipper Zero ( I put it in the Games folder)
3. Start the app and have fun ;)

A online compiler i use, is here:
